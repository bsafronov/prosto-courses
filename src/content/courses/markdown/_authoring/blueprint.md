# Course Blueprint: Основы Markdown

Версия: 1

Один Module ведёт от роли разметки через структуру документа к ссылкам и коду. Основная Practice Task в Уроке о структуре даёт две последовательные подсказки и разбор решения. Module Checkpoint объединяет изученные действия в памятке, а Capstone Demonstration переносит их в реальную инструкцию с Self-Assessment по наблюдаемым признакам и практикует все Learning Outcomes.
