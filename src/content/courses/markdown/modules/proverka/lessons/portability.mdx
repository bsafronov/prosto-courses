Ты получил исходник с таблицей и списком задач. В одном редакторе всё работает, в другом таблица остаётся набором вертикальных черт. Проблема не обязательно в синтаксической ошибке: возможно, автор и читатель подразумевали разные варианты Markdown.

## База и расширения

[CommonMark 0.31.2](https://spec.commonmark.org/0.31.2/) задаёт общую спецификацию для блоков и элементов внутри строк. [GitHub Flavored Markdown 0.29-gfm](https://github.github.com/gfm/) строится поверх CommonMark и добавляет расширения, включая таблицы и списки задач.

| Конструкция | CommonMark 0.31.2 | GFM 0.29-gfm |
| --- | --- | --- |
| ATX-заголовки `#` | да | да |
| ограждённые блоки кода | да | да |
| таблицы с `|` | нет | да, расширение |
| списки задач `- [ ]` | нет | да, расширение |

<Callout kind="error">
  Неверный подход: «Это Markdown, значит откроется одинаково везде». Название языка не фиксирует набор расширений и поведение конкретной среды.
</Callout>

## Сначала назови среду

Перед использованием расширения запиши, где документ будет опубликован. Для этого курса целевая среда — GitHub.com, а её текущие правила сверяются с [официальной справкой GitHub по форматированию](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax).

Внешняя справка дополняет курс, но основной путь не зависит от доступа к ней: необходимые различия уже перечислены в таблице выше.
