## Заголовки создают структуру

Количество символов `#` в начале строки задаёт уровень заголовка:

```md
# Название документа
## Большой раздел
### Подраздел
```

Уровни лучше использовать последовательно. После заголовка второго уровня обычно идёт заголовок третьего, а не четвёртого.

Заголовки — не способ сделать строку крупнее, а карта документа. В CommonMark количество символов `#` задаёт уровень ATX-заголовка; подробные правила и пограничные примеры собраны в [разделе 4.2 спецификации](https://spec.commonmark.org/0.31.2/#atx-headings).

<Callout kind="advanced">
  Некоторые редакторы поддерживают дополнительные варианты Markdown. Это необязательно для основного маршрута: сначала освой переносимую базовую разметку.
</Callout>

## Выделение помогает расставить акценты

Одинарные звёздочки создают *курсив*, двойные — **сильное выделение**:

```md
Это *важное* слово, а это **главный вывод**.
```

## Списки группируют связанные мысли

Для неупорядоченного списка поставь дефис перед каждым пунктом. Для последовательности используй числа.

```md
- тезис
- пример
- вывод

1. Открой файл
2. Добавь заголовок
3. Сохрани результат
```

Маркированный список подходит для равноправных пунктов. Упорядоченный — когда порядок меняет результат. Если шаги можно переставить без последствий, числа создают ложное обещание последовательности.
