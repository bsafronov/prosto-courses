## Ссылки соединяют материалы

Текст ссылки заключают в квадратные скобки, а адрес — в круглые:

```md
[Документация Astro](https://docs.astro.build/)
```

Осмысленный текст ссылки полезнее фразы «нажмите здесь»: читатель заранее понимает, куда перейдёт.

Это не только вопрос стиля. WCAG 2.2 рекомендует делать назначение ссылки понятным из её текста или программно определяемого контекста; см. [разбор критерия 2.4.4 «Link Purpose (In Context)»](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context.html).

<Callout kind="warning">
  Адрес может быть технически верным, а ссылка — всё равно неясной. Текст «здесь» не сообщает, откроется ли инструкция, отчёт или форма.
</Callout>

## Код сохраняет точное написание

Короткую команду или имя файла обрамляют обратными кавычками: `pnpm build`. Для нескольких строк используют блок из трёх обратных кавычек и при необходимости указывают язык.

````md
```js
console.log("Привет!");
```
````
