В этом модуле разметка становится инструментом решения читательской задачи. Ты сначала спроектируешь иерархию документа, затем добавишь ссылки и код так, чтобы шаги можно было выполнить без догадок.

Поддержка постепенно сокращается: от разбора готовой структуры — к самостоятельной инструкции для новой ситуации.
