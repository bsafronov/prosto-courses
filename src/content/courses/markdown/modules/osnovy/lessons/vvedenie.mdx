Представь инструкцию из двадцати строк. В текстовом редакторе всё выглядит терпимо, но после публикации читатель не различает название, шаги и предупреждение. Markdown решает не задачу «сделать красивее», а задачу «обозначить роль частей текста».

## Три слоя одного документа

У документа есть:

1. **содержание** — слова, которые читает человек;
2. **разметка** — знаки, обозначающие роль фрагмента;
3. **представление** — то, как выбранная система показывает эту роль.

Markdown — это лёгкий язык разметки. В обычный текст добавляются простые знаки, которые описывают его структуру: `#` обозначает заголовок, а `*` может выделить слово.

Исходный текст остаётся читаемым до преобразования в HTML или другой формат. Спецификация CommonMark описывает документ как последовательность блоков — например, абзацев, заголовков, списков и блоков кода — с элементами внутри строк, включая ссылки, выделение и код. См. [раздел «Blocks and inlines» спецификации CommonMark 0.31.2](https://spec.commonmark.org/0.31.2/#blocks-and-inlines).

## Первый документ

Создай файл `notes.md` и добавь строку:

```md
# Мои заметки
```

Расширение `.md` подсказывает инструментам, что файл содержит Markdown.
