# Course Brief: Python для аналитика

Версия: 1

Статус: одобрен Course Owner

Дата начала согласования: 2026-07-27

## Learner Profile и контекст применения

Основной learner — начинающий аналитик, который уверенно работает с таблицами
и формулами в Excel или Google Sheets, но ещё не использует Python для анализа
данных. Знание SQL не требуется.

Контекст применения — регулярный анализ выгрузки из рабочей системы или
таблицы: проверить качество, преобразовать данные, рассчитать показатели,
сравнить группы и передать выводы вместе с воспроизводимым notebook. Курс не
привязан к конкретной отрасли.

## Наблюдаемые входные capabilities

- открыть табличный файл и найти столбец по названию;
- использовать формулу для расчёта показателя по строкам;
- отфильтровать и отсортировать таблицу;
- объяснить разницу между исходными данными и рассчитанным показателем.

## Практическая потребность

Learner должен перейти от ручной обработки таблиц к воспроизводимому анализу:
загрузить CSV или XLSX, проверить качество данных, очистить их, рассчитать
показатели, выполнить группировку, построить графики и сформулировать выводы с
честно указанными ограничениями.

## Scope inclusions и exclusions

В основной маршрут входят:

- минимум синтаксиса Python, необходимый для чтения и изменения аналитического
  кода: значения, переменные, выражения, базовые коллекции, условия, циклы и
  небольшие функции;
- модель notebook: состояние kernel, порядок выполнения ячеек, перезапуск и
  последовательное воспроизведение;
- NumPy: `ndarray`, форма, размерность, `dtype`, индексация, маски,
  векторизованные операции и агрегации по осям;
- pandas: `Series` и `DataFrame`, загрузка CSV/XLSX, первичная диагностика,
  типы, пропуски, дубликаты, выбор и фильтрация, вычисляемые столбцы,
  группировка, сводные таблицы, объединение таблиц, даты и экспорт результата;
- Matplotlib и Seaborn: выбор базового графика под аналитический вопрос,
  подписи, шкалы, сравнение и честная интерпретация;
- воспроизводимый notebook: явные шаги, сохранённые зависимости, контрольные
  проверки, выводы и ограничения.

`openpyxl` используется как техническая зависимость чтения и записи XLSX; его
API не изучается.

Обзорно, без требования практического владения:

- Parquet как типизированный колоночный формат;
- Polars и DuckDB для иных профилей объёма и запросов;
- Plotly для интерактивной визуализации.

В Курс не входят:

- объектно-ориентированное проектирование, алгоритмы и структуры данных вне
  непосредственных аналитических задач;
- разработка пакетов, asynchronous programming и production deployment;
- web scraping, работа с API и SQL;
- машинное обучение;
- SciPy, statsmodels и продвинутая статистика.

Эти границы сохраняют фокус на анализе табличных данных, а не на подготовке
Python-разработчика.

## Learning Outcomes

После завершения Курса learner сможет:

- `reproduce-analysis` — создавать локальный Jupyter Notebook с
  зафиксированными зависимостями и воспроизводить его сверху вниз;
- `calculate-with-arrays` — выполнять аналитические расчёты средствами
  Python/NumPy, учитывая `shape`, `dtype`, маски и оси;
- `prepare-tabular-data` — загружать CSV/XLSX, диагностировать типы, пропуски и
  дубликаты, очищать данные с проверкой результата;
- `answer-with-transformations` — фильтровать, рассчитывать, группировать,
  сводить и объединять данные для ответа на аналитический вопрос;
- `communicate-findings` — выбирать графики, формулировать подтверждённые
  выводы и явно указывать ограничения анализа.

## Capstone Demonstration и evidence

Capstone Demonstration — воспроизводимый Jupyter Notebook с анализом нового
табличного набора данных.

Наблюдаемое evidence:

- CSV или XLSX загружен без ручного переноса значений в код;
- качество и типы данных проверены до расчётов;
- очистка данных объяснена и не скрывает потери наблюдений;
- рассчитаны показатели и агрегаты, отвечающие на аналитический вопрос;
- графики поддерживают выводы, а не заменяют их;
- выводы отделены от предположений и ограничений;
- notebook выполняется последовательно и сохраняет необходимые результаты.

## Time budget и Course Depth

Бюджет основного маршрута — 12 часов, включая study, practice, Module
Checkpoints и Capstone Demonstration. Необязательное углубление — до 2 часов.

Course Depth — прикладная база. После основного маршрута learner самостоятельно
анализирует малый или средний табличный набор данных в памяти одного компьютера,
но не выполняет статистический вывод, машинное обучение или
production-разработку.

## Capability Packs

Capability Packs не требуются. Платформа не предоставляет Python runtime и не
выполняет learner-код.

Основная практика проходит локально в JupyterLab с Python 3.14. Зависимости и
виртуальное окружение управляются через `uv`. VS Code с Jupyter extension может
использоваться как необязательная альтернативная оболочка, но основной маршрут
не зависит от неё.

Проверка открытой практики использует сохранённые результаты notebook и
Self-Assessment; автоматическое исполнение или тестирование кода платформой не
заявляется.

## Accessibility и safety

- Основная практика использует только синтетические обезличенные данные и не
  требует загрузки рабочих или персональных данных во внешний сервис.
- Dataset и описание ожидаемой структуры доступны локально.
- Инструкции покрывают Windows, macOS и Linux; различия команд обозначаются
  рядом с соответствующим действием.
- Установка и основной маршрут не предполагают административный доступ.
- Каждый learner-created график получает содержательный заголовок, подписи
  осей, единицы и текстовый вывод; смысл не кодируется только цветом.
- Разбор ошибок следует модели «наблюдаемый симптом → причина → исправление →
  повторная проверка» и не характеризует learner.
- Платформа не исполняет learner-код. Открытая практика проверяется через
  сохранённые результаты и Self-Assessment без утверждения об автоматической
  проверке.
