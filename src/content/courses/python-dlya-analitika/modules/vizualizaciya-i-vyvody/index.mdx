График — не финальное украшение notebook. Это ещё одна форма evidence.
Неподходящая агрегация, неясная единица или усечённая ось способны изменить
восприятие даже при правильной таблице.

В этом модуле ты:

- начнёшь с аналитического вопроса и grain evidence table;
- выберешь chart type по сравнению, а не по внешнему виду;
- построишь Matplotlib/Seaborn chart с title, units и доступным различением
  series;
- сформулируешь findings без причинных claims;
- назовёшь limitations и следующий проверяемый вопрос;
- передашь notebook после Restart and Run All.

Проверка модуля потребует короткое сообщение: evidence table, chart, два
вывода, ограничение и воспроизводимый project.

<Callout kind="key">
  Таблица хранит exact values, график помогает увидеть relationship, текст
  формулирует допустимый вывод. Ни одна часть не должна подменять остальные.
</Callout>
