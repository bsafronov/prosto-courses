Ты получаешь готовую evidence table. Задача — не пересчитать её с нуля, а
передать comparison без visual и causal ошибок.

```python
import pandas as pd

summary = pd.DataFrame(
    {
        "month": ["June", "June", "June", "July", "July", "July"],
        "channel": ["chat", "email", "phone", "chat", "email", "phone"],
        "median_hours": [4.0, 12.0, 8.0, 5.0, 14.0, 7.0],
        "tickets": [120, 80, 60, 140, 95, 70],
    }
)
```
