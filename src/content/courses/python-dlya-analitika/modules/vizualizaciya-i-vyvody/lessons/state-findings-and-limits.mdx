Последняя code cell не завершает анализ. Читателю нужны ответы:

- на какой вопрос отвечал notebook;
- какие данные и строки участвовали;
- какое evidence поддерживает каждый вывод;
- чего данные не позволяют утверждать;
- как повторить расчёт.

## Четыре уровня утверждения

| Уровень | Пример | Что требуется |
| --- | --- | --- |
| Fact из результата | Email median = 14 часов в July | Exact table или output |
| Comparison | Email выше chat на 9 часов в July | Два сопоставимых значения |
| Hypothesis | Возможно, email cases сложнее | Явная маркировка и новый вопрос |
| Causal claim | Сложность вызвала задержку | Design, которого здесь нет |

Наблюдательный notebook обычно поддерживает первые два уровня. Hypothesis
направляет следующую проверку, но не становится finding.

<Callout kind="key">
  Finding = claim + точное evidence + boundary. Если boundary отсутствует,
  читатель легко услышит больше, чем показывают данные.
</Callout>

## Структура передаваемого notebook

1. **Question:** population, period, measure.
2. **Environment:** Python/dependency instructions.
3. **Data contract:** sources, grain, keys, units.
4. **Quality:** baseline, issues, changes, controls.
5. **Transformation:** filters, measures, GroupBy/merge checks.
6. **Evidence:** exact summary table.
7. **Chart:** relationship и accessible labels.
8. **Findings:** numbered claims со ссылкой на evidence.
9. **Limitations:** missing coverage, synthetic context, no causal design.
10. **Reproduction:** Restart and Run All, `uv sync --locked`.

Эта структура не требует превращать каждую строку в отдельный heading. Она
делает dependencies и reasoning видимыми.

## Проверяй lineage перед текстом

```python
assert len(raw) == rows_baseline
assert ready["order_id"].is_unique
assert combined["_merge"].eq("both").all()
assert summary["revenue"].sum() == ready["revenue"].sum()
```

Только после прохода controls сформулируй finding:

> В July south revenue составила 5 500 ₽ против 2 200 ₽ у north в synthetic
> dataset.

Limit:

> Dataset содержит четыре February orders и не позволяет объяснить причину
> difference или переносить magnitude на реальные продажи.

Next question:

> Сохраняется ли difference на полном периоде и внутри одинаковых категорий?

## Не путай output и evidence

Notebook может хранить старый chart после изменения upstream code. Restart and
Run All пересоздаёт outputs, но ещё нужно глазами сравнить ключевые controls.
Перед передачей:

1. `uv sync --locked`;
2. Restart Kernel;
3. Run All Cells;
4. проверь asserts и final totals;
5. сохрани notebook;
6. убедись, что raw data path относительный и доступен получателю;
7. перечисли ограничения.

## Необязательное углубление: executable export

<Callout kind="advanced">
  Jupyter `nbconvert` может повторно выполнить notebook и создать HTML:

  ```sh
  uv run jupyter nbconvert --to html --execute analysis.ipynb
  ```

  Выполняй export только на synthetic или разрешённых данных: HTML может
  содержать outputs. Export не заменяет `.ipynb`, `pyproject.toml`, `uv.lock` и
  source files, если получателю нужно повторить анализ.
</Callout>
