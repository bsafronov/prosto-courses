Подходящий chart type всё ещё может вводить в заблуждение. Bar с осью от 11 до
14 визуально превращает небольшую разницу в пропасть. Две линии, различимые
только красным и зелёным, теряют смысл без цветового восприятия.

Честный chart сохраняет пропорцию, называет единицы и остаётся читаемым вместе
с текстовым evidence.

## Figure и Axes разделяют контейнер и данные

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

summary = pd.DataFrame(
    {
        "month": ["June", "June", "July", "July"],
        "channel": ["chat", "email", "chat", "email"],
        "median_hours": [4.0, 12.0, 5.0, 14.0],
    }
)

fig, ax = plt.subplots(figsize=(8, 4))
```

`fig` — весь output, `ax` — область с axes. Seaborn рисует data marks, а Axes
получает title, labels и scale:

```python
sns.barplot(
    data=summary,
    x="channel",
    y="median_hours",
    hue="month",
    errorbar=None,
    ax=ax,
)

ax.set(
    title="Медианное время решения обращений",
    xlabel="Канал",
    ylabel="Медианное время, часы",
    ylim=(0, 16),
)
ax.legend(title="Месяц")
fig.tight_layout()
```

Для bar baseline `0` важен: длина bar кодирует величину. Upper limit 16 немного
выше maximum 14 и не обрезает marks.

## Добавь различие кроме цвета

```python
hatches = ["//", ".."]

for container, hatch in zip(ax.containers, hatches):
    for bar in container:
        bar.set_hatch(hatch)
```

Legend names и разные hatch patterns дополняют color. Для line chart используй
`style`, markers и line dashes. Не кодируй series только цветом или только
позицией legend.

## Текст рядом ограничивает трактовку

Exact evidence:

| Month | Chat, hours | Email, hours |
| --- | ---: | ---: |
| June | 4 | 12 |
| July | 5 | 14 |

Допустимое описание:

> В synthetic dataset median выросла с 4 до 5 часов для chat и с 12 до 14
> часов для email. Email остаётся медленнее в обоих месяцах.

Недопустимый causal claim:

> Новый процесс ухудшил скорость email.

Dataset показывает comparison, но не содержит process intervention или
контроль альтернативных причин.

## Диагностируй anti-example

```python
fig, ax = plt.subplots()
sns.barplot(
    data=summary.loc[summary["channel"].eq("email")],
    x="month",
    y="median_hours",
    errorbar=None,
    ax=ax,
)
ax.set_ylim(11, 15)
```

Проблемы:

- title, axes labels и unit отсутствуют;
- bar baseline обрезан;
- exact values не показаны;
- маленький synthetic dataset может выглядеть как устойчивый trend.
