Проверка модуля интегрирует dates, вычисляемый показатель, many-to-one merge,
GroupBy и pivot. Вопрос:

> Какой регион лидировал по выручке в январе и феврале, и изменился ли лидер?

```python
import pandas as pd

orders = pd.DataFrame(
    {
        "order_id": ["O1", "O2", "O3", "O4", "O5", "O6", "O7", "O8"],
        "order_date": [
            "2026-01-05",
            "2026-01-10",
            "2026-01-15",
            "2026-01-20",
            "2026-02-05",
            "2026-02-10",
            "2026-02-15",
            "2026-02-20",
        ],
        "region": ["north", "north", "south", "south", "north", "north", "south", "south"],
        "category_id": ["C1", "C2", "C1", "C2", "C1", "C2", "C1", "C2"],
        "units": [2, 2, 3, 1, 1, 1, 3, 1],
        "unit_price": [1000.0, 1500.0, 500.0, 2000.0, 1000.0, 1200.0, 1000.0, 2500.0],
    }
)

categories = pd.DataFrame(
    {
        "category_id": ["C1", "C2"],
        "category": ["basic", "premium"],
    }
)
```

## Review guidance

- Population или period выбраны неявно → `select-filter-calculate`.
- Неясен итоговый grain или aggregation → `group-and-pivot`.
- После merge меняются rows/totals → `combine-and-check-tables`.
