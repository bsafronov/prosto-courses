В электронной таблице адрес `B2` одновременно указывает место и значение. В
Python имя переменной указывает на значение по смыслу:

```python
units = 3
unit_price = 750.0
discount_rate = 0.1

net_revenue = units * unit_price * (1 - discount_rate)
net_revenue
```

Результат — `2025.0`. Формула знакома, но вместо координат видны роли данных.
Это помогает проверить вопрос: `discount_rate` хранит долю `0.1`, а не десять
рублей и не строку `"10%"`.

## Тип определяет допустимые операции

Для основной аналитической работы достаточно сначала различать пять видов
значений:

| Python value | Пример | Аналитический смысл |
| --- | --- | --- |
| `int` | `3` | целое количество |
| `float` | `750.0` | число с дробной частью |
| `str` | `"paid"` | текстовая категория |
| `bool` | `True` | результат условия |
| `None` | `None` | значение отсутствует в Python-коде |

Проверь тип функцией `type`:

```python
type(units), type(unit_price), type("paid"), type(True), type(None)
```

Строка `"750"` похожа на число для человека, но Python не умножает её как
цену:

```python
price_text = "750"
price_number = float(price_text)
```

<Callout kind="warning">
  `None` не равен нулю. Ноль может быть наблюдаемым количеством, а `None`
  сообщает, что значение неизвестно. Подмена пропуска нулём меняет смысл
  данных.
</Callout>

## Список хранит последовательность

Python list похож на одномерный диапазон:

```python
daily_revenue = [1200.0, 850.0, 950.0]

first_day = daily_revenue[0]
last_two_days = daily_revenue[1:3]
total = sum(daily_revenue)
```

Индексация начинается с нуля: `daily_revenue[0]` — первое значение. Правая
граница slice не входит в результат, поэтому `[1:3]` выбирает позиции 1 и 2.

`len(daily_revenue)` возвращает число элементов, а `sum(daily_revenue)` —
сумму. Список допускает значения разных типов, но смешивать цены, статусы и
даты в одной последовательности неудобно для анализа. Позже NumPy даст
однородный array, а pandas — именованные столбцы.

## Словарь называет поля

Dictionary хранит пары «ключ → значение»:

```python
order = {
    "order_id": 1001,
    "units": 3,
    "unit_price": 750.0,
    "discount_rate": 0.1,
    "status": "paid",
}

gross_revenue = order["units"] * order["unit_price"]
net_revenue = gross_revenue * (1 - order["discount_rate"])
```

В этом примере словарь играет роль одной строки с именованными полями. Но это
только мост от знакомой таблицы к коду. Для множества строк основным
инструментом станет pandas DataFrame.
