Python list умеет хранить разные типы и свободно менять длину. NumPy array
делает другой обмен: обычно хранит элементы одного типа в прямоугольной форме.
За это ограничение аналитик получает компактную модель массовых вычислений.

Официальное beginner guide NumPy описывает `ndarray` как однородную
N-dimensional структуру и вводит базовые атрибуты
[`shape`, `ndim`, `size` и `dtype`](https://numpy.org/doc/stable/user/absolute_beginners.html).

## Форма отвечает на вопрос «что где находится»

```python
import numpy as np

units = np.array(
    [
        [12, 15, 11],
        [8, 7, 10],
    ],
    dtype=np.int64,
)
```

Пусть строки — регионы `north`, `south`, а столбцы — товары `basic`,
`standard`, `premium`.

```python
units.ndim
units.shape
units.size
units.dtype
```

Смысл:

- `ndim == 2` — две оси;
- `shape == (2, 3)` — две строки и три столбца;
- `size == 6` — шесть значений;
- `dtype == int64` — каждый элемент хранится как целое число.

<Callout kind="key">
  `shape` — не декоративная подпись. Она задаёт, какие измерения совместимы и
  что будет означать следующая операция.
</Callout>

## Индекс указывает позицию по каждой оси

```python
north_basic = units[0, 0]
south_premium = units[1, 2]
north_all_products = units[0, :]
standard_all_regions = units[:, 1]
```

Результаты:

- `north_basic` → `12`;
- `south_premium` → `10`;
- `north_all_products` → array `[12, 15, 11]`;
- `standard_all_regions` → array `[15, 7]`.

Двоеточие означает «все позиции этой оси». В `units[:, 1]` выбираются все
строки и второй столбец.

## dtype влияет на смысл и результат

Среднее значение целого array может быть дробным:

```python
units.mean()
```

NumPy вернёт float. Если добавить неизвестное значение, обычный integer array
не может хранить `np.nan` без изменения dtype:

```python
units_with_gap = units.astype(np.float64)
units_with_gap[1, 1] = np.nan
```

Это не значит, что float автоматически «лучше». Тип нужно выбирать по данным:
целое количество, дробная цена, boolean mask. Несовместимый dtype может
привести к ошибке, лишней памяти или неожиданному преобразованию.

## Необязательное углубление: view или copy

<Callout kind="advanced">
  Slice NumPy часто создаёт view: изменение `part = sales[:, :2]` может изменить
  исходный `sales`. Если нужна независимая стадия, используй
  `part = sales[:, :2].copy()`. Проверь поведение на одном значении и восстанови
  notebook через Restart and Run All.
</Callout>
