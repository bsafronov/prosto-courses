В предыдущем Lesson форма объясняла расположение значений. Теперь она
объясняет действие операции. Вместо цикла по каждой ячейке NumPy применяет
выражение к совместимым arrays.

## Broadcasting связывает разные формы

Количество товаров по двум регионам:

```python
import numpy as np

units = np.array(
    [
        [12, 15, 11],
        [8, 7, 10],
    ],
    dtype=np.int64,
)

prices = np.array([500.0, 800.0, 1200.0])
```

`units.shape == (2, 3)`, а `prices.shape == (3,)`. Последняя длина совпадает:
каждая цена относится к своему столбцу. NumPy растягивает 1D array цен по
строкам:

```python
revenue = units * prices
```

Результат:

```text
[[ 6000. 12000. 13200.]
 [ 4000.  5600. 12000.]]
```

Механизм называется
[`broadcasting`](https://numpy.org/doc/stable/user/basics.broadcasting.html).
Он работает только для совместимых dimensions. Совпадение числа элементов
само по себе недостаточно: важна позиция каждой оси.

## Маска выбирает значения по условию

```python
large_units = units >= 10
selected_revenue = revenue[large_units]
```

`large_units` — boolean array той же формы. `selected_revenue` становится
одномерным array значений, где mask равна `True`.

Маска сохраняет правило выбора в коде. Сравни:

```python
paid = np.array([True, False, True])
amounts = np.array([900.0, 1200.0, 1350.0])

paid_revenue = amounts[paid].sum()
```

Результат — `2250.0`.

## Axis определяет, что сворачивается

```python
by_product = revenue.sum(axis=0)
by_region = revenue.sum(axis=1)
total = revenue.sum()
```

- `axis=0` сворачивает строки и оставляет один итог на столбец: по товару;
- `axis=1` сворачивает столбцы и оставляет один итог на строку: по региону;
- без `axis` сворачиваются все значения.

Результаты:

```text
by_product = [10000., 17600., 25200.]
by_region  = [31200., 21600.]
total      = 52800.
```

<Callout kind="key">
  Не запоминай axis как «0 — столбцы». Спроси: какую ось операция сворачивает и
  какая ось остаётся в результате?
</Callout>

## Проверяй форму результата

```python
assert revenue.shape == units.shape
assert by_product.shape == (3,)
assert by_region.shape == (2,)
assert total == 52800
```

Эти проверки ловят неверную ось раньше, чем массив с правдоподобными числами
попадёт в вывод.

  пропуск исключается из знаменателя. Сравни `mean` и `nanmean` на копии
  `net_revenue` с одним `np.nan` и запиши, почему итог изменился.
