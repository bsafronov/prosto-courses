В таблице формула живёт рядом с данными. В notebook код, данные, результат и
пояснение тоже находятся рядом, но появляется скрытое состояние: ячейки можно
выполнить не по порядку, а зависимости — случайно установить вне проекта.

В этом модуле ты построишь надёжное основание:

- `pyproject.toml` описывает прямые зависимости;
- `uv.lock` фиксирует exact environment;
- clean kernel показывает, выполняется ли notebook с нуля;
- Python выражает значения, коллекции и небольшие правила;
- NumPy применяет одну операцию сразу к массиву;
- `shape`, `dtype`, маска и ось помогают предсказать результат до запуска.

Проверка модуля объединит setup, Python и NumPy: ты восстановишь нарушенный
notebook и докажешь, что расчёт не зависит от случайного порядка ячеек.

<Callout kind="key">
  Воспроизводимость начинается не с красивого notebook, а с явных зависимостей,
  исходных данных и порядка вычислений.
</Callout>
