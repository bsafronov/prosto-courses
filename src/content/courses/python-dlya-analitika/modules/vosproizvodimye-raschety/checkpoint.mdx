## Неисправный notebook

Фрагменты расположены не по dependency order.

Фрагмент A:

```python
region_revenue = revenue_after_returns(units, returns, prices)
region_totals = region_revenue.sum(axis=1)
```

Фрагмент B:

```python
import numpy as np
```

Фрагмент C:

```python
def revenue_after_returns(units, returns, prices):
    net_units = units - returns
    assert net_units.shape == units.shape
    assert np.all(net_units >= 0)
    return net_units * prices
```

Фрагмент D:

```python
units = np.array(
    [
        [3, 2, 1],
        [4, 1, 2],
    ]
)
returns = np.array(
    [
        [0, 1, 0],
        [1, 0, 0],
    ]
)
prices = np.array([500.0, 800.0, 1200.0])
```

Фрагмент E:

```python
assert region_revenue.shape == (2, 3)
assert region_totals.tolist() == [3500.0, 4700.0]
assert region_revenue.sum() == 8200.0

large_cells = region_revenue >= 1500
assert int(large_cells.sum()) == 3
```

## Что повторить при затруднении

- Project не восстанавливается → вернись к «Проект и notebook без магии».
- Непонятен `None` или тип → «Значения и коллекции вместо ячеек».
- Функция возвращает `None` → «Условия, повторения и небольшие функции».
- Теряется смысл позиции → «Как NumPy хранит набор чисел».
- Перепутан итог по оси → «Маски, оси и векторные расчёты».
