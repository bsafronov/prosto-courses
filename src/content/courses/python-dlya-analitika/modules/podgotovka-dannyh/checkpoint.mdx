Проверка модуля объединяет три действия: загрузить файл с явным контрактом,
диагностировать symptoms и очистить только то, что можно обосновать. Результат
должен оставлять audit trail.

Запусти bootstrap cell:

```python
from pathlib import Path

import pandas as pd

data_dir = Path("data")
data_dir.mkdir(exist_ok=True)

orders_source = pd.DataFrame(
    {
        "order_id": ["7001", "7002", "7002", "7003", "7004", "7005", "7006"],
        "order_date": [
            "2026-07-01",
            "2026-07-02",
            "2026-07-02",
            "bad-date",
            "2026-07-04",
            "2026-07-05",
            "2026-07-06",
        ],
        "units": [2, 1, 1, 3, None, 0, 4],
        "unit_price": [500.0, 1200.0, 1200.0, 450.0, 800.0, 1000.0, 600.0],
        "status": ["paid", "paid", "paid", "paid", "paid", "cancelled", "paid"],
        "region": ["north", "south", "south", "north", "south", "north", " SOUTH "],
    }
)

orders_source.to_csv(data_dir / "module-2-orders.csv", index=False)
```
