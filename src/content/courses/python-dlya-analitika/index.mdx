В электронной таблице легко получить ответ один раз. Сложнее объяснить, какие
строки вошли в расчёт, повторить его на новой выгрузке и доказать, что очистка
не исказила результат. Python полезен аналитику именно здесь: шаги анализа
остаются в коде и могут быть выполнены заново.

Ты пройдёшь полный путь:

1. создашь локальный проект и воспроизводимый Jupyter Notebook;
2. освоишь только тот Python, который нужен для аналитических задач;
3. поймёшь массивы NumPy и векторные вычисления;
4. загрузишь и проверишь CSV/XLSX в pandas;
5. очистишь, сгруппируешь и объединишь таблицы;
6. построишь графики в Matplotlib/Seaborn;
7. сформулируешь выводы и ограничения;
8. соберёшь новый анализ в Capstone Demonstration.

Основная практика выполняется локально. Платформа показывает объяснения,
условия, feedback и Self-Assessment, но не исполняет Python-код.

<Callout kind="warning">
  Не используй в учебной практике рабочие выгрузки с персональными или
  конфиденциальными данными. Все datasets Курса синтетические и создаются
  локально Course-provided bootstrap cells.
</Callout>

## Инструменты

Reference stack проверен вместе на Python 3.14.6:

- uv 0.11.29 для Python, зависимостей и `uv.lock`;
- JupyterLab 4.6.2;
- NumPy 2.5.0;
- pandas 3.0.5;
- Matplotlib 3.11.1 и Seaborn 0.13.2;
- openpyxl 3.1.5 как engine для XLSX.

Точные версии нужны для одинакового поведения примеров. Официальные
[Python release notes](https://www.python.org/downloads/release/python-3146/),
[NumPy user guide](https://numpy.org/doc/stable/user/) и
[pandas user guide](https://pandas.pydata.org/docs/user_guide/) дополняют Курс,
но не требуются для решения core tasks.

## Граница Курса

Курс учит анализировать малые и средние табличные datasets в памяти одного
компьютера. SQL, API, web scraping, машинное обучение, продвинутая статистика и
production-разработка оставлены для отдельных Курсов. Parquet, Polars, DuckDB
и Plotly появляются только как необязательная карта следующих инструментов.
