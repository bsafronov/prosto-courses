В четырёх cases ребёнок «отказался от группового задания». Твоя задача —
сохранить общий workflow и не выбрать plan по названию диагноза.

  **Case A — РАС.** Ребёнок говорит фразами, понимает written sequence,
  перестаёт участвовать после незапланированного изменения; изображения
  игнорирует.

  **Case B — СДВГ.** Ребёнок начинает activity, но при десятиминутном ожидании
  встаёт и берёт materials; с ролью помощника участвует дольше.

  **Case C — синдром Дауна.** Ребёнок раньше участвовал, но три недели
  сонлив, меньше отвечает после тихого часа; семья сообщает о храпе.

  **Case D — ТНР.** Ребёнок молчит после длинного вопроса, но выбирает верную
  emotion picture при короткой instruction; hearing давно не проверяли.

  Для каждого создай строки:

  1. что известно;
  2. что нельзя заключить;
  3. две hypotheses;
  4. следующая проверка;
  5. одна adaptation;
  6. partner/route;
  7. measure.

  Затем ответь: какая одна общая привычка психолога полезна во всех cases?

Если adaptation можно перенести между всеми четырьмя cases без изменения
reasoning, проверь: возможно, она выбрана по привычке, а не по profile.
