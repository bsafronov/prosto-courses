## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for this repository. See `docs/agents/issue-tracker.md`.

### Issue completion

After implementing an issue, completing the required review and verification,
and committing the work, close the GitHub issue with a concise summary of the
implementation, checks, and commit. Do not leave a completed issue open for the
user to close manually.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses the single-context domain documentation layout. See `docs/agents/domain.md`.
