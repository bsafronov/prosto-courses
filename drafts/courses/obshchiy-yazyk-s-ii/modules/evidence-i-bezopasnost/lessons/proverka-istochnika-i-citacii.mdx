В смоделированном пакете материалов есть правдоподобно оформленная ссылка.
Рядом написано: «Четырёхнедельный пилот повышает производительность любого
специалиста на 24 процента». Карточка источника описывает другую аудиторию и
другую метрику, а число 24 относится к доле участников, завершивших опрос.
Даже существующий URL не сделал бы такой тезис подтверждённым.

Проверяется не ссылка сама по себе. Проверяется связь между
конкретным тезисом и тем, что источник действительно позволяет заключить.

## Пройди цепочку от тезиса к ограниченному выводу

Для каждого существенного утверждения создай отдельную строку реестра
подтверждений:

| Поле | Проверочный вопрос |
| --- | --- |
| Тезис | Что именно читатель примет за факт или основание решения? |
| Подтверждающий фрагмент | Какой точный соседний фрагмент подтверждает тезис? |
| Авторитетность | Почему источник вправе сообщать это: первичное исследование, стандарт, владелец данных? |
| Дата | Достаточно ли свеж источник для этого свойства? |
| Применимость | Совпадают ли аудитория, задача, продукт, регион и условия? |
| Ограниченный вывод | Какой самый узкий вывод выдерживает все проверки? |

Порядок важен. Если сначала принять красивый вывод, легко искать фразу, похожую
на него по словам. Начни с точного тезиса, открой источник, прочитай фрагмент с
соседним контекстом и только затем сформулируй ограниченный вывод.

RAG и WebGPT сделали происхождение найденных фрагментов видимее, но получение
материала через поиск не гарантирует поддержку каждого вывода
([Lewis et al., 2020](https://arxiv.org/abs/2005.11401),
[Nakano et al., 2021](https://arxiv.org/abs/2112.09332)).
В ALCE даже сильные исследованные системы не всегда обеспечивали полную
поддержку длинного ответа ссылками; поэтому считать количество ссылок
недостаточно
([Gao et al., 2023](https://arxiv.org/abs/2305.14627)).
Документация провайдера также описывает привязку к источникам (`grounding`) как
способ снизить, а не устранить галлюцинации
([Anthropic, Reduce hallucinations](https://platform.claude.com/docs/en/test-and-evaluate/strengthen-guardrails/reduce-hallucinations)).

### Разбери четыре разрыва

Тезис: «Пилот подходит нашей команде и повысит удержание на 24 процента».

| Проверка | Найденное | Что ломается |
| --- | --- | --- |
| Авторитетность | Корпоративный блог пересказывает исследование без данных | Авторитетность для точного эффекта |
| Дата | Страница продукта описывает интерфейс трёхлетней давности | Актуальность живого свойства |
| Применимость | Исследование проведено со студентами на восьминедельной программе | Перенос на руководителей и четыре недели |
| Фрагмент | В абзаце 24 процента — доля ответивших на опрос | Связь числа с заявленным результатом |

Ссылка может быть полезна для более узкого вывода, например: «В исследовании
этой аудитории измеряли удержание после восьми недель». Она не получает право
подтвердить другой результат или автоматический перенос на новый контекст.

<Callout kind="key">
  Ссылка делает тезис проверяемым только тогда, когда точный фрагмент
  поддерживает именно этот тезис, а авторитетность, дата и применимость подходят
  решению.
</Callout>

  **Карточка B.** Сгенерированный тезис: «24 процента участников улучшили
  производительность». Тип источника: первичное исследование студентов
  восьминедельной программы, 2023 год. Фрагмент: «Последующий опрос завершили
  24 процента приглашённых». Производительность не измерялась.

  **Карточка C.** Сгенерированный тезис: «Эти правила хранения действуют для
  нашего бесплатного чата». Тип источника: карточка документации API без даты
  проверки. Фрагмент: «Настройки относятся к запросам через API по указанному
  договору». Бесплатный чат в области применимости не назван.

  Для каждой карточки сам выбери достаточный вердикт и заполни `тезис /
  фрагмент / авторитетность / дата / применимость / вердикт / ограниченный
  вывод / следующая проверка`. Разрешены вердикты: `поддержан`, `поддержан
  частично`, `не поддержан`, `недостаточно данных`. Не исправляй тезис догадкой.

  Изменённый случай: первичное исследование надёжно описывает исследованную
  выборку, но не твою аудиторию. Сформулируй один допустимый вывод и один вывод,
  который потребовал бы нового подтверждения. Затем добавь в реестр один
  существенный тезис собственной задачи.

Иногда проверка заканчивается не новым фактом, а честной границей: доступного
подтверждений недостаточно. Следующий урок превратит «не знаю» в управляемое
решение о следующей проверке.
